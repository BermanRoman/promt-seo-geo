# Сайт-курс и сайт-учебник: SEO-разборы, разметка, подачи, книга

Читают прораб и ревьюер, когда сайт автора — бесплатный курс, тренинг или учебник, а разборы статей приводят читателя из поиска в урок. Общие правила разборов — `razbor-rules.md`, ядро — `semantics.md`, раздел 12, поисковики и разметка — `search-and-ai.md`, вёрстка — дизайн-система сайта (правила вёрстки проекта лежат в `workspace/`; здесь не копируется). Решения конкретного сайта, записанные в его `decisions.md`, главнее.

## 1. Разборы и уроки
- SEO-разборы лежат отдельно от уроков: своя папка (раздел) и свой список. Урок остаётся уроком и под SEO не переписывается; весь SEO живёт в разборе.
- **Каждый разбор ведёт ровно в один урок** — тот, который продолжает ответ на запрос читателя; поле «ведёт в урок» — в карточке допуска. Разбор не пересказывает урок (бриф «урок не трогаем», `semantics.md`, раздел 12).
- Учебник с закрытым маршрутом: главы идут только вперёд и назад, блоки «разобрано отдельно» не ставятся, если автор их отклонил. Разборы — вход в сайт, а не продолжение главы.
- Ссылка на канал автора (Telegram) — в каждом уроке и каждом разборе; на главной лендинга с HVCO её нет. Формулировку кнопки и место берёт дизайн-система.
- Оглавление, выданное как подарок за прохождение: страница есть, кнопок на неё нет, ссылка только в конце последнего урока, `noindex`, вне `sitemap` и `llms.txt` (решение автора для конкретных сайтов; общий вид — дизайн-система).

## 2. Разметка (учебные страницы)
| Страница | Типы |
|---|---|
| Главная | `WebSite` + `Course` (`hasPart` — уроки) + `Person` |
| Урок | `LearningResource` + `Person` + `BreadcrumbList` |
| Разбор | `Article` (`isBasedOn` — урок, куда он ведёт) + `Person` + `BreadcrumbList` + `FAQPage` |
| Учебник-книга | `Book` с `hasPart` (главы) и `DefinedTermSet` / `DefinedTerm` для словаря — по решению сайта |

`Course` без `offers` для бесплатного курса допустим: расширенный результат Course info Google снят в 2025 году, разметка нужна как описание сущности. Описание урока в разметке — его строка «Урок о том…». Разметка совпадает с видимым текстом (общие правила — `search-and-ai.md`, раздел 6).

## 3. Подачи после выкладки
Обязательный порядок и состояния — `launch`, `infrastructure`, `workflow.md` («Состояния выпуска»). Для сайта-курса дополнительно:
- **Файл ручного переобхода** (`workspace/данные/переобход.md` или рядом с сайтом): главная, уроки и разборы тремя разделёнными группами, ссылки пачками по 10 (ручная отправка в Вебмастере принимает ограниченный пакет). Пересобирается после каждой выкладки; не перезаписывать без изменений: меняется только время. Порядок групп — по решению автора сайта, по умолчанию как в `post-deploy.mjs` (первыми главная и новые страницы).
- До добавления сайта автором в кабинеты Вебмастера, Search Console и Bing ничего не подаётся: в кабинете сайта нет, подача бессмысленна. Закрытый сайт перед этим скрыт (`Disallow: /`, `noindex`), открывается по слову автора.
- Карта — `sitemap-index.xml` (как у всех сайтов автора), `/sitemap.xml` отвечает 301 на неё; мета-тег подтверждения Вебмастера — на главной. IndexNow со своим ключом сайта; снимки archive.org фоном.
- **Страница 404** — в стиле сайта (ответ 404, `noindex`, ссылка на главную); анимированная заглушка допустима как выбор автора, длительность и правила движения — дизайн-система.
- Ошибка API Вебмастера «права не подтверждены» при подтверждённых в интерфейсе правах — не чинить, переобход вручную по файлу; квота Bing исчерпана — остаток доезжает на следующий день.

## 4. Книга из сайта-учебника (необязательный шаг)
Если автор хочет книгу: EPUB 3 и FB2 (Kindle берёт EPUB), PDF — по желанию. Текст берётся из **собранного сайта** (блок текста главы в `dist`), а не из исходников: типографика, ёлочки, ссылки на словарь идут как на сайте; скрипт останавливается, если сайт собран старее текстов. Порядок и заголовки — из того же списка глав, что у сайта. Без картинок, если графики нет. Обложка и титул с ©, именем и годом; внутренние ссылки между главами работают внутри книги, остальное ведёт на сайт.
Проверка: корректный XML (`xmllint`), `epubcheck` (нужна Java: `brew install openjdk epubcheck`, по согласию автора), нет служебных меток, нет прямых кавычек, оглавление совпадает с сайтом, объём главы совпадает с исходником в пределах ±2 % слов. Копию выкладывают на archive.org (Community Texts, S3-совместимый API, ключи только из `workspace/.env`) после готовой книги и по слову автора. Образец — сборка книги на одном сайте-учебнике (пример с одного сайта-курса).
