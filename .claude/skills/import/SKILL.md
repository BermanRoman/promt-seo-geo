# Импорт архива

Цель — материалы автора в `workspace/content/materials/`, по одному файлу на пост или статью. Текст автора не переписывается.

## Telegram-канал
1. Объяснить человеку, как выгрузить (по одному шагу, дождаться «готово»):
   1. Открыть Telegram Desktop (не телефон и не веб-версию) — канал — меню «⋮» — «Экспорт истории чата».
   2. Оставить галочку «Фотографии», снять «Видео», «Голосовые», «Файлы» — они сайту не нужны.
   3. Формат — **«Машиночитаемый JSON»**. Период — «за всё время».
   4. Нажать «Экспортировать» и прислать путь к папке (обычно `~/Downloads/Telegram Desktop/ChatExport_…`).
2. Запустить сначала пробно: `cd engine && node scripts/import-telegram.mjs "<папка>" --channel <имя канала> --dry-run`. Показать итог: сколько войдёт, сколько коротких постов останется за бортом.
3. **Короткие посты** (меньше 250 слов) на сайт не идут: тонкие страницы вредят всему сайту в поиске. Если у автора почти все посты короткие — предложить порог ниже (`MIN_WORDS=150`) или собрать короткие посты одной темы в один материал (с согласия автора, текст — его, только склейка). Решение — за человеком.
4. Боевой запуск без `--dry-run`. Отчёт — `workspace/данные/импорт-<дата>.md`.

## Папка с файлами
`cd engine && node scripts/import-folder.mjs "<папка>" [--recursive]`. Сначала с `--dry-run`. Файлы `.docx` скрипт не берёт — предложить сохранить их как .md или .txt.

## SEO материалов (делает система, без вопросов)
Для каждого материала (новые — каждый, архив — пакетами по 20):
- `seoTitle` — до 70 знаков, если заголовок автора не похож на запрос («Охота» → «Охота на … : что произошло»). Заголовок автора (`title`) не трогать.
- `description` — 120–160 знаков, главный факт в начале; переписать, если скрипт взял неудачный первый абзац.
- `keywords` — 3–6 формулировок, как ищут люди (по желанию; сверить 2–3 главные с Wordstat, если подключён MCP yandex-ads, — через журнал, `knowledge/semantics.md`, раздел 9).
- `draft: true` — для материалов, которые автор не хочет на сайте (спросить один раз списком, если есть сомнительные: рекламные посты, розыгрыши, личное).

## Финал
`cd engine && npm run build` — сборка должна пройти. Коммит в `workspace/` («Импорт архива»). Человеку одной строкой: сколько материалов на сайте, сколько коротких осталось за бортом и почему. Дальше — этап `audit`.
