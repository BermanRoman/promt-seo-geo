# Сводка

1. Снять данные (что подключено, то и снимаем; ошибки одного сервиса не останавливают остальные):
   `cd engine && FORCE=1 node scripts/webmaster.mjs stats; FORCE=1 node scripts/gsc.mjs stats; FORCE=1 node scripts/bing.mjs stats`.
   Метрика — через MCP yandex-ads (`yd_metrika_report`: визиты, источники, цели `cta_*`, `read`), если подключён.
2. Сравнить с прошлой сводкой (`workspace/данные/сводки/`).
3. Ответ человеку — **5 строк**:
   - показы и клики из поиска за неделю против прошлой (Яндекс, Google, Bing);
   - что вошло в индекс и что выпало;
   - 3 лучших запроса и страницы;
   - где сайт цитируют нейросети (если видно по переходам из Алисы, ChatGPT, Perplexity в Метрике);
   - одно конкретное действие на неделю (например: «обновить тему X — по ней растут показы», «материал Y без разбора, а спрос есть»).
4. Подробности — `workspace/данные/сводки/<дата>.md`. Дата сводки — в `workspace/.deploy/last-report`.

Первые 2–4 недели после запуска данных почти нет — так и сказать, без натяжек.
