# Запуск

## 1. Разборы по архиву (если в брифе «делаем по архиву»)
По плану аудита — первые 10 разборов и 3 живые темы — тем же конвейером, что `material-ready` (шаги 2–5), без выкладки. Не больше 3 агентов одновременно.

## 2. Просмотр
`cd engine && npm run build`, локальный просмотр во встроенном браузере (`npx astro preview` с `WORKSPACE`). Проверить самим на 375 и 1280 px: главная, материал, разбор, тема, рубрика, автор, 404. Потом показать человеку: адрес локального просмотра и 3–4 снимка.

**Здесь нужно «лей».** Это единственное обязательное согласие в системе. Правки — сделать, показать снова.

## 3. Выкладка
1. `site.config.json` → `indexing: true`.
2. `cd engine && npm run deploy` (сборка, заливка, IndexNow, переобход в Вебмастере, архив).
3. Проверить живой сайт: главная, материал, разбор отвечают 200; `robots.txt` открыт; `sitemap-index.xml` отдаётся; у страниц нет `noindex`; превью (og:image) отвечает 200.
4. Отправить карты сайта: `node scripts/gsc.mjs sitemap`, `node scripts/bing.mjs sitemap` (если есть ключи API); Bing на старте не знает сайт — `node scripts/bing.mjs submit`. Переобход в Яндексе (API или вручную в Вебмастере) отправлять один раз: он идёт в пределах бюджета обхода сайта. Новый сайт Яндекс обходит быстро, а у сайта, который уже есть в Вебмастере, страницы встают в очередь — повторная отправка её не ускоряет, только тратит дневной лимит.
5. Снимок исходной точки: `node scripts/webmaster.mjs stats`, `node scripts/gsc.mjs stats`, `node scripts/bing.mjs stats` — что есть, то и снимаем; файл `workspace/данные/исходная-точка-<дата>.md`: сколько страниц, что в индексе, первые показы. От него считается рост.

## 4. Человеку
Одно сообщение: адрес сайта, сколько страниц вышло, что будет дальше («Яндекс и Google начнут показывать сайт через 1–4 недели; когда выйдет новый материал — напишите „материал готов“»), и шпаргалка фраз:
- «материал готов» — опубликовать и сделать разборы;
- «сводка» — что показали поисковики за неделю;
- «проверь сайт» — раз в месяц;
- «поменяй …» — любая правка обычными словами;
- «что дальше?» — следующий шаг.

Коммит в `workspace/` («Запуск»).
