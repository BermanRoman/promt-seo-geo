# promt-seo-geo

Мультиагентная система для Claude Code: делает из Telegram-канала или заметок эксперта сайт, который находят Яндекс и Google и цитируют нейросети — Алиса, ChatGPT, Perplexity.

Система собрана на живом проекте — [analytics.bermanshop.ru](https://analytics.bermanshop.ru): материалы автора, разборы событий под поисковый спрос, живые страницы тем, разметка Schema.org, llms.txt, Яндекс Вебмастер, Search Console, Bing, IndexNow.

> **Статус: в разработке.** Версия 1.0 ещё не готова.

## Как запустить

Откройте Claude Code и напишите:

```
Установи систему из https://github.com/BermanRoman/promt-seo-geo и начни
```

Дальше Claude всё сделает сам и будет задавать вопросы по одному: о вас, о вашем контенте, о сайте. Руками придётся только завести домен и хостинг и подключить поисковые консоли — система проведёт по шагам.

## Что вы получите

- Сайт на вашем домене или поддомене: ваши материалы, страница автора, разборы тем, которые ищут.
- Тексты вашим голосом: система учится по вашим текстам, а если их мало — пишет по методичке инфостиля ([promt-copywriting](https://github.com/BermanRoman/promt-copywriting)).
- Дизайн под вас, а не шаблон «как у всех».
- После каждого нового материала — публикация и разборы по одной фразе «материал готов», раз в неделю — сводка из поисковиков.
