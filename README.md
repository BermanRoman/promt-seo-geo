# promt-seo-geo

Мультиагентная система для Claude Code и Codex: делает из Telegram-канала или заметок эксперта сайт, который находят Яндекс и Google и цитируют нейросети — Алиса, ChatGPT, Perplexity.

Система собрана на живом проекте — [analytics.bermanshop.ru](https://analytics.bermanshop.ru): материалы автора, разборы событий под поисковый спрос, живые страницы тем, разметка Schema.org, llms.txt, Яндекс Вебмастер, Search Console, Bing, IndexNow.

> **Версия 1.2** (07.11.2026). Пишите, что работает не так, — в [Issues](https://github.com/BermanRoman/promt-seo-geo/issues).

## Как запустить

Откройте Claude Code или Codex и напишите:

```
Установи систему из https://github.com/BermanRoman/promt-seo-geo и начни
```

Дальше агент всё сделает сам и будет задавать вопросы по одному: о вас, о вашем контенте, о сайте. Руками придётся только завести домен и хостинг и подключить поисковые консоли — система проведёт по шагам.

## Что вы получите

- Сайт на вашем домене или поддомене: ваши материалы, страница автора, разборы тем, которые ищут.
- Тексты вашим голосом: система учится по вашим текстам, а если их мало — пишет по методичке инфостиля ([promt-copywriting](https://github.com/BermanRoman/promt-copywriting)).
- Дизайн под вас, а не шаблон «как у всех».
- После каждого нового материала — публикация и разборы по одной фразе «материал готов», раз в неделю — сводка из поисковиков.

## Что нового

**1.2 — 07.11.2026**
- Темы для разборов проходят допуск до написания: что именно ищут, какой ответ ждут в выдаче и есть ли он в вашем материале. Одного числа показов мало.
- Каждый текст вычитывается по методичке копирайтинга, потом сверяется, потом его читает отдельный «читатель из поиска», который не видел ни переписки, ни правил. Пока он не получил ответ на свой запрос, страница не выходит. Если отдельного читателя запустить нельзя, страница выходит только с вашего явного разрешения.
- Сайт публикует только принятые версии разборов и тем: любая правка после приёмки — повторная проверка, выкладка это проверяет. Страницы, вышедшие до версии 1.2, закрепляются как есть.
- Wordstat больше не выдаёт ошибку сервиса за нулевой спрос; подачи в поисковики при сбое сервиса не теряются, а ждут в очереди.
- Работает в Claude Code и в Codex: правила хранятся в одном месте.

**1.1 — 26.10.2026**
- Проверка разборов строже: в выводах на страницах — только ваши мысли из материала, ничего за вас не дописывается. Если источники расходятся с вашим текстом, ваш текст не трогаем, а присылаем вам список расхождений.
- Юридическая проверка источников глубже: не только сайт, но и сама страница — кто её издал и кто выступает в стенограмме.
- Несколько материалов можно выложить одной публикацией: меньше подключений к хостингу.
- Подсказки по хостингу: как проверить, что сайт видят роботы нейросетей, и что делать, если хостинг их не пускает; как убедиться, что настройки сервера действительно работают.

**1.0 — 19.10.2026.** Первая версия: сайт, импорт из Telegram и папки, конвейер разборов, поисковые консоли, сводки.

## Для агента

Этот раздел — инструкция для Claude Code и Codex. Человеку читать его не обязательно.

### Установка
1. Проверь Node.js 20+ и git: `node -v`, `git --version`. Нет Node — предложи поставить с nodejs.org (LTS) и подожди.
2. Склонируй систему в папку, которую выберет человек (по умолчанию `~/promt-seo-geo`):
   `git clone https://github.com/BermanRoman/promt-seo-geo.git ~/promt-seo-geo`
3. Канон копирайтинга (голос автора и вычитка) по закреплённой версии: `cd ~/promt-seo-geo && node scripts/check-dependencies.mjs --install`. Не скачался — не страшно, есть выжимка в `knowledge/infostyle-summary.md`; вычитка тогда идёт по ней, и это отмечается в отчёте.
4. Зависимости движка: `cd ~/promt-seo-geo/engine && npm install`.
5. Проверка: `WORKSPACE=../examples/demo npm run build` — сборка примера должна пройти.
6. Дальше работай из папки `~/promt-seo-geo`: прочитай `AGENTS.md` (мастер-промт) и начни с навыка `onboarding`. Если сессия открыта не в этой папке — предложи человеку открыть новую сессию в ней, чтобы подхватились навыки и исполнители (`.claude/` для Claude Code, `.agents/` и `.codex/` для Codex).

### Обновление
`git -C ~/promt-seo-geo pull && npm --prefix ~/promt-seo-geo/engine install && node ~/promt-seo-geo/scripts/check-dependencies.mjs --install`. Зависимость с устаревшей версией скрипт покажет как `stale revision`: тогда `git -C ~/promt-seo-geo/vendor/promt-copywriting fetch && git -C ~/promt-seo-geo/vendor/promt-copywriting checkout <revision из dependencies.json>`. Данные пользователя лежат в `workspace/` и при обновлении не меняются.

### Устройство
- `AGENTS.md` — мастер-промт: этапы, правила, фразы пользователя. `CLAUDE.md` подключает его для Claude Code.
- `workflow.md` — роли, этапы страницы, реестр приёмки, состояния выпуска, пределы.
- `.agents/skills/` — этапы: `onboarding`, `voice`, `import`, `audit`, `infrastructure`, `design`, `launch`, `material-ready`, `report`, `checkup`.
- `roles/` — исполнители: `razbor-writer`, `topic-writer`, `topic-updater`, `copy-editor`, `razbor-checker`, `search-reader`, `site-reviewer`.
- `.claude/` и `.codex/` — тонкие входы для Claude Code и Codex, ведут в канон.
- `knowledge/` — правила: разборы и живые темы, семантика и допуск, поиск и нейросети, закон РФ, безопасность, инфостиль.
- `engine/` — движок сайта на Astro и скрипты (сборка, выкладка по SSH, IndexNow, Яндекс Вебмастер, Search Console, Bing, импорт из Telegram, приёмка, проверки); тесты — `npm test`.
- `dependencies.json` и `scripts/check-dependencies.mjs` — закреплённый канон копирайтинга в `vendor/`.
- `docs/migration.md` — что изменилось при переходе на версию 1.2.
- `workspace/` — данные пользователя (не в репозитории).
